## Repository layout note

This repository supports two layouts so Codespaces setup remains stable during refactors:

1. **Root-level project layout** (project files live at repository root).
2. **Nested `trust/` layout** (project files live under `trust/`).

The root `.devcontainer` scripts auto-detect which layout is active and bootstrap the correct project root.
